We sent an AI agent shopping at 14,991 stores. Not one let it buy alone the first time.

ONAA Agent Checkout Report #1 · data as of Nov 15, 2026 · raw data

TL;DR

  • About half the stores let our agent do the shopping. At 49% it searched, filled a cart and reached "ready to pay" with no human help.
  • Zero let it pay alone on the first try. A person always had to step in at least once.
  • One OK can be enough. At about a quarter of stores (3,513), the buyer approves Shop Pay once and the agent could pay alone after that.

The experiment

Lots of stores now say "AI agents welcome." They publish a small file that tells agents how to shop there. We found 32,306 of them. So far we've visited 14,991.

At each one, our agent behaved like any stranger's agent would. It searched, picked one item, opened a checkout, and then cancelled. We never paid and never placed an order.

How far it got

Getting in, searching and opening a checkout worked almost everywhere (90%). The big drop comes right at the end: paying.

Where it ended up

What kind of human OK do stores need?

"A human has to step in" can mean very different things. We sorted the 13,481 stores where the agent opened a checkout into four kinds:

  • The buyer finishes on the store's page (46%). The agent hands over a checkout link, and the buyer reviews and completes it.
  • The buyer pays each time (28%). The agent does everything else, and the buyer types a card for every order.
  • The buyer OKs once, then the agent pays alone (26%). Shop Pay lets the buyer link it to the agent one time.
  • Pre-approved payment: 0. This is the "agent can pay from day one" kind: a payment mandate the buyer signs in advance (Google's AP2), card-network agent tokens, or Stripe's shared payment tokens. None of the 10,925 store manifests we read offer any of these yet.

Two honest notes on this chart. The Shop Pay group is based on what the store offers, not on watching it work: we stop before paying, so we can't see the one-time code or a bank check (3-D Secure) that may still pop up. And 2,836 stores offered no way for an agent to pay at all, only the buyer.

Two real stores, two different endings

A US garden-supply store. The agent found the product, opened a checkout and got a delivery quote. It only needed the buyer's email and phone, which an agent can pass along. Then the buyer types a card, or approves Shop Pay once. Smooth.

A UK beauty shop. The agent built the order fine. Then the checkout asked for an extra on-page step that only a person in a browser can do, so the buyer has to finish it. That extra step showed up at 41% of the stores we checked.

(We don't name stores without their permission.)

The three things that stop agents most

  1. "Who are you?" 87% of checkouts want the buyer's email or phone. Easy, if the agent has it.
  2. "Click here first." 41% add an on-page step built for humans.
  3. "Log in." 5% want the agent signed in to an account.

How agents can pay today

  • Card typed by the buyer: 10,575 stores. A human every time.
  • Shop Pay: 7,966 stores. A human once, then the agent can pay alone (if nothing else blocks it).
  • Google Pay: 134 stores.
  • Crypto or agent-native payment at checkout: none seen yet.

Where they'll ship

Real delivery quotes from 5,872 stores. The top five were nearly tied: US 5,555 · UK 4,727 · Germany 4,711 · Japan 4,581 · Korea 4,537. (Canada, Australia, France, Singapore and India testing has just started.)

The honest fine print

  • Observed, not verified. Every number is what our agent saw on one visit. No store has confirmed its result yet (verified: 0). Stores change their setup all the time.
  • Who's in the sample. Only stores that already advertise agent shopping, and almost all run on Shopify. So "49%" means 49% of agent-ready stores, not of all online shops.
  • We stop before paying. Anything that happens at the payment step itself (one-time codes, bank checks) is outside what we can see.
  • Still counting. 17,315 stores aren't checked yet. Next issue shows what changed.
  • Stores aren't affiliated with ONAA. ONAA never buys anything or holds money.
