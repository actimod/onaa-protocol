# ONAA Protocol v0.1 test vectors

Directory: [`specs/test-vectors/v0.1/`](test-vectors/v0.1/) · Normative text: [`onaa-protocol-v0.1.md`](onaa-protocol-v0.1.md) §12 · Status: DRAFT

> **TEST-ONLY KEYS.** Every private key in these files is public by construction. Most are derived as `seed = SHA-256("ONAA-TEST-ONLY-KEY:" + label)`, and one is the RFC 8037 Appendix A example key. Anyone can recompute them. Never use them to sign anything real. Production verifiers **MUST NOT** trust them, and every attestation here is `test_only: true`. All host names use the reserved `example.com` / `.invalid` domains (RFC 2606). All parties, SKUs and prices are fictional samples, and every handoff is `mock`.

## Regenerate and check

```bash
pip install -e packages/onaa-protocol
python -m onaa_protocol.vectors write specs/test-vectors/v0.1    # deterministic: Ed25519 + fixed clock/ids
python -m onaa_protocol.vectors check specs/test-vectors/v0.1    # exit 1 if any committed file differs
python -m onaa_protocol.conformance --offline --vectors specs/test-vectors/v0.1   # ONAA-V-* checks
```

The fixed clock is `T0 = 2026-11-12T12:00:00Z`. Validate envelopes at `validate_at` (T0 + 2 min), not at the current time.

## Notes for other-language implementers

* Signing input = `ASCII(protected) + "." + BASE64URL(JCS(object without "signature"))`. BASE64URL is unpadded. Compare your JCS output byte-for-byte with `worked_example.payload_jcs`.
* The `protected` header is plain compact JSON with sorted keys. Its byte form does not need to be canonical, because verifiers use the received string.
* Ed25519 is deterministic: your signer must reproduce `worked_example.signature_b64url` from `test-only-keys.json` `buyer`.
* The files are ASCII-only (`\uXXXX` escapes). Decode them as JSON before canonicalizing; never canonicalize the file text itself.
* The secret scanner (`scripts/secret_scan.py`) and gitleaks run over these files. Their format avoids PEM blocks and compact JWS triples that start with `eyJ…eyJ…`, so no allowlist entry was needed.
